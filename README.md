# Programação Orientada a Objetos I em Java

Trilha de revisão e prática inspirada na disciplina de Programação Orientada a Objetos I do IFF, Campus Itaperuna, em 2026.1. O material usa Java 17 e foi escrito em português.

A primeira etapa vai da estrutura de um programa em Java às associações entre objetos. A segunda aprofunda os princípios de orientação a objetos com estudos de caso, exercícios e um projeto integrador.
