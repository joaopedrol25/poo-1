## Referências de Java 17

- Expressões, operadores e atribuição de valores. [Java Language Specification, cap. 15](https://docs.oracle.com/javase/specs/jls/se17/html/jls-15.html)
- Declaração de classes, construtores, herança, métodos abstratos e sobrescrita. [Java Language Specification, cap. 8](https://docs.oracle.com/javase/specs/jls/se17/html/jls-8.html)
- Arrays e comportamento dos índices. [Java Language Specification, cap. 10](https://docs.oracle.com/javase/specs/jls/se17/html/jls-10.html)
- Métodos de String, coleções, datas e outros tipos usados nos exemplos. [Documentação da biblioteca padrão do Java 17](https://docs.oracle.com/en/java/javase/17/docs/api/index.html)
